## 二、与检索 / 推荐的关系

- 检索：`knowledge_points` 作为加权字段（权重 0.6）参与 BM25 打分；`chapter` 权重 0.5。
- 同考点推荐：第一级按共享细考点召回，无候选时退到同章节兜底；候选优先返回未做过的已核验题。
- 当前 81 题细考点零复用，同考点召回主要靠推荐题组内的刻意对齐（Cache / 页面置换 / 子网划分三组）；后续扩库可按上位考点归并同名细考点，提升同考点召回率。
