# Alpha 七页公共外壳验收（TD-01）

验证于 2026-11-15 在从 `main@91987ff55169208611f54bbc559c8dcf75be2cbc` 建立的分支上进行。连续练习以 PR #29 合入后的实现为基线，本地 FastAPI 使用 v1.2-alpha 正式题库，共 81 题。

## 改动

- `App.vue` 统一挂载 `AppShell`。各页面渲染自身内容，路由移除 `fullLayout` 分支。
- 共用一套七页导航、模型状态和 Toast。侧栏链接用 `aria-current` 标识当前页，跨页保留当前题目、会话、模式和练习题号。
- 检索结果页可直接打开。尚无结果时提供返回搜题的入口。有结果时用原检索的会话 ID 关联答案揭示和追问记录，继续答疑进入同一会话的答案页。
- 桌面显示完整侧栏，窄窗口切换为图标侧栏，小屏改为顶部导航。开发联调开关在开发环境按原场景使用。

## 七页浏览器回归

Chrome 与 Microsoft Edge 分别以 1440、768、390、320px 宽运行生产构建。七页都通过了导航可点、当前页唯一高亮、单一主区域、单一提示容器和页面无横向滚动检查。

| 页面 | 实际检查 |
| --- | --- |
| 提问 `/` | 用 COP006 完整题干发起搜题，跳转答案页并建立会话。 |
| 检索结果 `/result` | 初次进入显示空态。搜题后显示真实来源，从历史页进入后可直接返回提问。Chrome 另测了在结果页揭示答案、继续原会话答疑，回到结果页后仍可看到该条追问。 |
| 答案 `/answer` | 打开真实推荐并切换到 COP005，选项完整，答案等待主动查看，成功提示可见。 |
| 步骤 `/steps` | 从当前练习切入，题号和会话参数保留。 |
| 教学 `/teaching` | 导航和显示正常，从侧栏回到答案仍是原练习题。 |
| 历史 `/history` | 学习记录可打开，可通过侧栏继续当前练习。 |
| 资料 `/materials` | 资料页可打开，320px 宽下统计卡片换行，页面无横向滚动。 |

- 当前后端的 health 缺少模型字段时显示「模型状态未知」。在受控响应中验证了已连接、未配置和未知三种提示，切页时显示一致。快速切换七页共请求 health 一次。
- 开发环境可打开联调开关，显式演示有标记。生产构建七页均隐藏开发开关，含浏览器残留旧演示配置的场景。
- 浏览器检查无页面 JavaScript 异常。跨页追问用受控答疑响应，真实模型及线上发布由候选版验证。

## 复跑

后端沿用 [开发指南](developer-guide.md) 和正式题库。前端执行以下命令可复跑自动化并预览生产构建。

```bash
cd frontend
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

本轮 `npm test` 和生产构建通过。`test:contract` 覆盖七页导航和共享提示、结果空态、同题多个会话时按原会话显示，以及原会话删除后的处理。
