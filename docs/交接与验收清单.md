## 一、启动方式

| 端 | 步骤 | 说明 |
| :--- | :--- | :--- |
| 后端 | `cd backend && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt && copy .env.example .env` | 填 `LLM_API_KEY/LLM_BASE_URL/LLM_MODEL`；改 .env 后重启 |
| 后端启动 | `uvicorn main:app --reload --port 8000` | 健康检查 `GET /api/health` |
| 前端 | `cd frontend && npm ci && npm run dev` | 打开 http://localhost:5173 |
| 前端构建 | `npm test`（5 套）+ `npm run build` | 交付前必过 |
| 数据自检 | `cd backend && python tools/convert_questions.py stats data/questions.json` | 81 题、skipped 空 |

## 三、演示主流程

1. 搜题（三态：原题/相似/未命中）。
2. 答疑（直接解析 / 引导模式，引导不泄底）。
3. 同考点推荐 → 切题 → 教学（切题后新题从「未揭示」开始）。
4. 资料导入 → 导出 → 清空 → 导入 → 刷新 → 答疑切片（P1 资料闭环）。
