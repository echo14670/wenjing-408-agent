## 一、启动方式

从仓库根目录开始。后端使用 Python 3.11，前端需要 Node.js 20 或以上，CI 使用 Node.js 22。

在 PowerShell 启动后端

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path -LiteralPath '.env')) { Copy-Item -LiteralPath '.env.example' -Destination '.env' }
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

需要调用真实模型时，先在本地 `.env` 填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。启动后检查 `http://localhost:8000/api/health`，从 `backend` 目录执行 `.\.venv\Scripts\python.exe tools/convert_questions.py stats data/questions.json` 可核对题库。在同一目录运行 `.\.venv\Scripts\python.exe -m pytest -q` 可复测后端。

另开终端，从仓库根目录启动前端

```powershell
cd frontend
npm ci
npm run dev
```

打开 `http://localhost:5173`。交付前从 `frontend` 目录运行 `npm test` 与 `npm run build`。

1. 搜题（三态：原题/相似/未命中）。
2. 答疑（直接解析 / 引导模式，引导不泄底）。
